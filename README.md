# Stackpath-Learning-Platfrom

A hands-on learning dashboard covering computer science, networking, databases, system design, cloud infrastructure, distributed systems, performance, AI, and engineering case studies.

- 54 lessons and 9 practice projects.
- Worked examples with expected output and exercises. JavaScript examples run in the browser.
- English, বাংলা, and Lietuvių. New visits default to English.
- Language preference, completion marks, and notes are stored locally in the browser.

## Run locally

Open `dist/index.html` in a browser, or serve the static files from the repository root.

```sh
python -m http.server 8000 --directory dist
```

Open `http://localhost:8000`. Individual Python, SQL, Docker, and other examples list their own prerequisites.
